Work in small verified steps: run the relevant tests (pytest -q tests) and the gate script after each change,
read validation/<GATE>.json, and only claim PASS when the JSON says PASS.  Keep every number in reports
generated by scripts (skqd.report.GateResult); never edit a number in a report by hand.

Respect the 30-minute rule: if a run exceeds 30 minutes on this machine, stop it, re-parametrize (fewer shots,
--quick, smaller sector), and record both the reduced run and what the full run would need (desktop RTX
3070, Slurm GPU cluster, QPU) in the report.

When done: append an entry to prompts/LOG.md (prompt file, gate, result, commit hash, open issues), commit,
and if the gate passed run `python scripts/run_gate.py <GATE> --push`.  If blocked after two attempts, write
validation/BLOCKED.md (the runner does this automatically on FAIL) and stop; the planner takes over.
