## Glossary

- **Statevector**: the full list of $2^n$ complex amplitudes of an $n$-qubit state; complex128 = double precision.
- **Trajectory**: one noisy run in which the random errors (Pauli operators $X$, $Y$, $Z$) actually happened are drawn first and inserted into the circuit; one trajectory gives one measured bit string (one *shot*).
- **Clean-shot fraction $f$**: the probability, in the model, that a shot has no error at all (gates, idling and readout).  **Acceptance**: the fraction of shots that the package's codec decodes into the circuit's own sector.
- **$f_{\rm hit}$**: the reference-string hit fraction divided by the ideal probability of the reference string. **$f_{\rm ideal}(\delta)$**: the fraction of shots whose pre-readout distribution is within total-variation distance $\delta$ of the ideal one (times the readout survival of the reference string).  **$r_{\rm nc}$** $=f_{\rm hit}/f_{\rm ideal}(10^{-3})$, the near-clean ratio of the package's gate CF_traj (`reports/CF_traj.md`).
- **TV distance**: $\tfrac12\sum_s|q(s)-p(s)|$ between two distributions; 0 = identical, 1 = disjoint.
- **Class A / class B**: operator-exact / exact only on the circuit's own reference input (reviews/001 note 1).

So the large memory charge of the Helios model lowers $f$ much more than it lowers the ideal-sample fraction.
- **Reviewer's note 5 (does class B propagate errors differently?):** compare, circuit by circuit in table 3.5, $f_{\rm hit}$ with $f$ and $r_{\rm nc}$ between the classes under the same model.  $r_{\rm nc}>1$ means the reference-string estimator over-counts the ideal-sample fraction (near-clean shots), $r_{\rm nc}<1$ that faulty shots fall *off* the reference string more than in proportion. - **Noise placement:** analytic $f$ is on native circuits, trajectories on the IR (report 002 (g)); for the frozen 2x3 family the IR has more two-qubit gates than the optimised native form, so its sampled $f$ is lower than its analytic $f$ (compare tables 3.3 and 3.4).

- **Class B validity:** class B circuits are valid only as 'prepare own reference, one coarse step, measure' (reviews/001 note 1); every noisy test here is exactly that use.
